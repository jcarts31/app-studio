# App studio

Everything that belongs to the studio rather than to a single app. Cloned to `C:\dev\_studio\`.

- `owner-profile.md`: who the owner is and how apps are made. Every skill reads it.
- `INDEX.md`: every app and idea, its stage, and what's waiting on the owner.
- `ideas/<slug>/`: an idea's files before it becomes a project.
- `backlog.md`: ideas jotted down without starting them.
- `lessons.md`: what each project taught, and what changed because of it.
- `templates/expo-app/`: starter files laid over every new app (added with the first new app).
