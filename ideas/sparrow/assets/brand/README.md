# Sparrow brand assets

**`logo.svg` is a placeholder** (first concept, 2026-11-09): a simple sage sparrow facing
right. It will be refined in the asset pass, where the owner picks from three concepts.

- 100×100 viewBox, transparent background, main color #4F6F5F (sage).
- `outline`: the bird. `details`: the eye, dropped from the monochrome icon.
- Drawn inside the middle ~66% so it survives icon masks.
- `brand.json` holds icon, splash and favicon settings for `app-setup`.

`brand.json` follows the studio's usual fields (icon, adaptive, monochrome, splash, favicon);
check it against Spellfound's at setup, since Spellfound's file wasn't reachable when this was
written.
