# Editing Sparrow's content

Everything Sparrow says, and the numbers that tune it, live in the files in this folder. You can
change them without touching code. Builders fill in this guide as each file is added.

| File | What it holds | Status |
|---|---|---|
| `strings.yaml` | Every label, button, message and empty state | coming in M1 |
| `guardrails.yaml` | What the reviewer checks for (political, controversial figures, never-do list) | coming in M5 |
| `posting.yaml` | Default posting times, platforms, how many of each kind of post a week | coming in M6 |
| `cards.yaml` | Verse and quote card styles | coming in M5 |
| `voices.yaml` (+ `voices.xlsx`) | Trusted voices and their verified quotes | coming in M4 |
| `drafting.yaml` | How Sparrow is asked to write drafts | coming in M5 |
| `tuning.yaml` | Numbers: spending cap default, sync timing, which Claude models | coming in M1 |
