# Decisions

- 2026-11-08, owner: posts go to the owner's own accounts only.
- 2026-11-08, owner: target platforms are TikTok, YouTube Shorts, X, Threads, Instagram, Facebook, Pinterest and others.
- 2026-11-08, owner: approve a week of posts at a time, then it posts automatically.
- 2026-11-08, director: working title "Daily Bread", slug `daily-bread`.
- 2026-11-08, owner: pivot. Personal app on the owner's computer, powered by Claude: owner shares verses, influences, lessons, prayers and thoughts; Claude writes polished posts with images/music; owner approves; it learns from interactions and publishes. Generic verses/quotes only sometimes.
- 2026-11-09, owner: Go. Build it as its own desktop app on the owner's PC, calling Claude behind the scenes (Claude API key with a spending cap; always-stop item when set up).
- 2026-11-09, owner: the app holds everything: personal Bible journal with tracking, approved asset library (music, images, video) reused by the bot, voice/priorities learning, posting, post history, one inbox for replies, and stats.
- 2026-11-09, owner: Claude learns from performance and audience too: numbers, comments and notifications feed what it suggests and how it writes.
- 2026-11-09, director: start with Facebook, Instagram, Threads, YouTube and X posted directly (cheap route, ~$2-4/month); TikTok and Pinterest later. Claude drafts replies; the owner approves (no auto-replies).
- 2026-11-09, owner: add a reviewer agent that checks every post before it's queued and flags problems: poor timing given world events, quotes from controversial figures, anything political, plus (director) misattributed quotes, copyright, and the never-do list. Flags show in the weekly review with the reason; the owner decides. A last check runs near posting time, with a way to hold scheduled posts if something big happens.
- 2026-11-09, director: open for planning: whether posting-time checks and scheduled posting need the PC on, or a tiny always-on piece.
- 2026-11-09, owner: design direction A, Morning Pages (sage and mist, Literata + Figtree, calm journal-first).
- 2026-11-09, owner: name is Sparrow (Matthew 10:29-31). Slug `sparrow`, app ID `com.jcarts.sparrow`. Folder renamed from ideas/daily-bread.
- 2026-11-09, owner: design locked as v1 (Morning Pages, Sparrow, 5 key screens). Owner will use it before deciding changes; changes come back through design. Director: plan the build journal-first so the owner can use it early.
- 2026-11-09, owner: Sparrow syncs across all the owner's devices, including the phone (Pixel 9 Pro). Same app on PC and Android; phone layouts need a design pass (comes back through app-design).
- 2026-11-09, owner: use a small always-on cloud helper: syncs devices (journal, prayers and private entries end-to-end encrypted, so the helper can't read them), holds the approved week, runs the reviewer's last-minute news check, posts on time, collects replies, and takes "Hold all posts" from any device. Exact service and price to confirm at planning (always-stop: costs money, stores personal data).
- 2026-11-09, owner: the Library is mainly the bot's pantry: owner and Claude build it up together (images, music, clips, verses, quotes) so the bot has plenty to pull from.
- 2026-11-09, owner: the Library holds a list of trusted voices (e.g. C.S. Lewis). The bot may draw quotes only from people on that list.
- 2026-11-09, director: each trusted voice keeps a bank of verified quotes (exact words, book or sermon, where it was checked). The bot uses only quotes from that bank, never quotes written from memory, because misattributed Lewis quotes are common. Each voice also carries a copyright note: public domain (e.g. Spurgeon, Augustine, Bunyan) vs still under copyright (Lewis: short quotes with credit only, no long passages). The reviewer still checks every quote. New Library sections need a mockup before building.
- 2026-11-10, owner: MVP scope approved as recommended. MVP: journal (verses KJV/BSB/WEB built in, tags, prayers, search), encrypted sync across PCs and phone with recovery key, voice learning, library (images, verses, trusted voices with verified quotes), Claude drafts, reviewer (draft check, last-minute news check, Hold all posts), This week, posting to Facebook, Instagram, Threads with history. Later: Inbox, Insights, X, YouTube Shorts with music and clips. Future: TikTok, Pinterest, "Sparrow noticed" patterns, auto-suggested library finds.
- 2026-11-10, owner: OK to the cloud helper storing data (journal end-to-end encrypted; library images not encrypted since they're public), Claude reading entries the owner allows it to draft from (private entries never sent), and about $1-4/month (Claude with a hard cap, news checks ~30c, Cloudflare free or $5 max).
- 2026-11-10, director: shape: one Expo app for Android (native) and PCs (installable web app from Edge, offline, own window); helper on Cloudflare (Workers + D1 + R2 + cron). Claude key and platform tokens live only in the helper.
- 2026-11-10, owner: plan approved (Checkpoint 3): 7 milestones, 28 tasks.
- 2026-11-10, owner: autonomy: check in after each milestone.
- 2026-11-10, owner: build route: local for now (Claude Code on the PC, wireless adb to the Pixel); add the cloud route once the owner is happy and has tested everything.
